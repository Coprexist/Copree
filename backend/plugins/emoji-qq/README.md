# QQ 表情包

往 Copree 里加一套 QQ 风格表情：正文里写 :id: 或直接打 unicode 表情，各通道都能显示。

## 内容

- emoji.json：表情清单（id / 名字 / unicode 字符 / 可选的图片文件）
- 图片只接受 .png/.jpg/.jpeg/.gif/.webp（SVG 在同源下能带出脚本，刻意不支持）

## 需要的权限

- **不需要网络、不需要凭据**
- 读自己的 emoji.json 与图片资源；平台负责把表情写进消息正文

## 用法

- 标准表情直接用 unicode 字符
- 自定义表情写短码 :id:（首字母开头，如 :qq_shy:）
- 老写法 [表情:名字] 只作为输入兼容，会被归一成上面两种
