# 关键词自动回复

命中关键词时给 AI 注入一条回复指令——AI 看到关键词就知道该说什么，而不是把原话无脑复制回去。

## 需要的权限

- **不需要网络、不需要凭据**
- 只在回复链路里注册一个 inject 技能（不改系统提示词的其它部分）

## 行为

- 技能类型 keyword_autoreply（category: inject）
- 配置里的关键词命中后，把「命中关键词 X，请按 Y 回应」注入到本轮提示词
- 不命中时什么都不做，不占上下文

## 配置

| 键 | 说明 |
| --- | --- |
| keywords | 关键词列表 |
| inject_text | 命中时注入的指令 |
