## 🧭 设计原则

- **生命范式 > 工具范式**：AI 是群聊的"居民"，不是等待调用的 API
- **纯函数核心**：业务逻辑抽离为纯函数，IO 封装为薄编排层
- **数据自持**：用户完全控制自己的数据，联邦按需开启
- **渐进增强**：功能默认简单，深度用户可解锁全部参数
