# 协议端账号风险：被踢之后怎么判、怎么救

> 起因：2026-11-16，用户 **忆中影**（QQ 2771196834）接在本机 NapCat 上的号，04:01 收到
> `[KickedOffLine] [下线通知] 你的账号当前登录已失效，请重新登录。`，当晚 23:08 扫码并经手机确认后
> 两秒被拒（`ErrType 1 / ErrCode 5`）。
> 本文把那次排查的判据、社区实证与养号规则固化下来——下次同类问题不必重新推演。

---

## 一、先分清三种「掉线」，混为一谈会越救越糟

社区里大量「越挂越容易被踢、最后被冻结」的案例，根因是把下面三种当成同一种在救。

| 形态 | 日志特征 | 真实原因 | 正确处置 |
|---|---|---|---|
| **网络层断流** | `1006514 网络连接异常` → `账号状态变更为离线`，**没有** `KickedOffLine` | NAT/路由器回收空闲长连接 | 只重连，**不要扫码** |
| **服务端踢线** | `[KickedOffLine] [下线通知] …` | 同账号在别处登录（手机切号最常见）、风控判定异常 | 先快速登录，失败再扫码；**不要反复重启** |
| **僵死态** | `CheckLoginStatus` 返回 `isLogin: true` 但 `loginError` 有值；收不到也发不出 | 登录态已废，客户端没意识到 | 重启 worker，用缓存 token 登回 |

判据顺序是 **日志 > 端口 > API 字段**。`get_status.online` 会假在线（长连接断了它仍可能报 `online: true`），
`6099` 端口通只说明 Node 进程活着，**不代表登录着**。

---

## 二、「登录已失效」到底是谁干的

两句文案必须分开看：

| 文案 | 含义 |
|---|---|
| 您的账号已在另一台终端登录 | 真被挤掉，正常现象，重登即可 |
| 你的账号当前登录已失效，请重新登录 | 服务端吊销票据，属于异常 |

后者有两个来源：

1. **手机 QQ「切换账号」≠ 退出登录**。小号会话仍在后台，服务端看到两端同时在线，就把 PC 侧判为「登录态已失效」——
   这是社区公认最常见的踢线原因。用完要在小号界面**退出登录**，不是切回大号。
2. **风控判定登录环境异常**。此时往往伴随「扫码确认后被拒」，而不是单纯踢线。

## 三、为什么有人从来没被踢

同一批用 Linux + Docker 跑 NapCat 的人，结果能差一个数量级：

- 「我在 linux 设备上跑的，**几个月没掉过登录**」
- 「我也 linux/docker，**挂了几个月都没事**，后来部署到海外都没被下过」
- 「我那个就是 Linux 上面跑的，**一天基本上四五个小时掉一次**」

**同样的部署方式、同样的版本，结论完全不同——所以差别不在 NapCat，在号。**

社区给的解释：

- 「如果你的号**体质好**的话也不会掉」
- 「因为你的号被腾讯盯上了，**风控等级提升了，建议先养一下号**」
- 有人实测：小号隔几小时被踢；**换了个号、手机上也登着那个号，稳定两个多月没掉**

所以排查顺序应该是：**先怀疑号，再怀疑环境**。同一个协议端换号就稳，是号的问题；
换号仍然掉，才去查 IP、容器、版本。

## 四、养号与止损规则

来自 [napcat-guardian](https://github.com/wjy2468/napcat-guardian) 的踩坑记录与社区实证：

1. **别让同一个号多端同时在线**（手机「切换账号」要改成「退出登录」）。
2. **别反复重试**。重启风暴 = 连续无效登录尝试 = 风控触发器，社区大量账号因此被冻结。
   一次失败就熔断，冷却几小时再试。
3. **机器人号要有正常使用痕迹**：头像、昵称、少量真实好友/群。新号、小号更容易被风控。
4. **别在更新到最新版 QQ 后立刻挂 NapCat**，保持官方推荐版本。
5. **会员不防风控**。风控看设备指纹、登录地、行为模式，与会员等级无关。
6. **有线网络优于 WiFi**（WiFi 网卡省电会导致空闲断流）。

## 五、我们平台的处置原则

- 控制台归协议端，平台只保证后端连得上它（见 `docs/plugin-dev/channel-plugins.md` §4.7）——
  账号怎么登、要不要人脸验证，是用户和腾讯之间的事，平台不代劳。
- **不做自动反复重试**。登不上就是登不上，重连只保持一个克制间隔，不制造连续无效登录。
- 状态要给**人话**：区分「协议端没起来」「号没登」「被踢/被吊销」三种，而不是笼统显示离线。
- 出现「扫码确认后被拒」，正确建议是**停手冷却 + 换号或改用官方机器人**，不是继续扫。
