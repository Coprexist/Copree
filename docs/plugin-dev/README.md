## 建议阅读顺序

1. 先分清要写哪一类：**行为插件**（`@skill`，管「AI 能做什么」）/ **服务插件**（`@service`，管「进程里跑着什么」）。
2. 服务插件里若是接外部平台，读[写一个通道插件](./channel-plugins.md)；若是给群视界加工具，读[世界工具插件开发](./world_tools_plugin.md)。
3. 插件要影响 AI 看到的**环境**时，读[环境上报接口](./environment-api.md)——它是一份公共契约，不看你写的是哪类插件。

## 约定

- **插件 id 取自目录名**，作者不写 id；
- **公共契约只有一份**：接口签名与常量从 `app/services/plugin/api.py` 导出，文档只描述它，不另立说法；
- **新增插件开发文档一律进本目录**，不要再散到 `docs/dev/` 或 `docs/group_world/`。
