# 环境上报接口（插件公共契约）

> 版本：v1.1（草案）
> 契约来源：`app/services/plugin/api.py`（`environment` 契约 + `ENV_TEXT_KEY` + `ENV_PUBLIC_KEYS`）
> 判定与投递机制：[能力懒加载](../dev/capability_lazy_loading.md)、[帧、锁与重建点](../dev/frame_lifecycle.md)

## 1. 范围与术语

插件向平台上报**某个会话当前的环境**。平台不解释环境的语义，只负责：等值判定、置脏、作用域解析、
通知投递、锁定 / 解锁。

- **环境**：会话级（状态帧级）的当前状况——在哪个群 / 私信、接没接渠道、绑没绑世界这类。
- **插件**：加载中的 `ServicePlugin` 实例。
- **已告知值**：上一次已让该会话的 AI 知晓的那份环境。它是**平台侧状态**，插件不保存。

## 2. 契约

```python
async def environment(self, *, origin: str | int) -> dict[str, str | int | bool] | None
```

可选实现；未实现即该实例不提供环境。

`origin` 是该插件在这个会话上的**对端标识**——平台从会话作用域解析后传入。插件怎么理解它由插件自己决定
（QQ 插件就当群号用），接口不预设「群」：私信、非群组平台同样适用。

| 返回 | 含义 |
|---|---|
| `dict` | 扁平；键为 `str`，值为 `str` / `int` / `bool`；不嵌套、无浮点、无 `None`（缺失用「键不出现」表达） |
| `None` | 当前无环境（未接入 / 不属于本实例） |
| 其他 | 违规：丢弃本次上报，记 error，**不视为环境消失** |

## 3. 保留键 `text`

`text` 是平台保留的**覆盖键**，与公共键分开导出（`ENV_TEXT_KEY` / `ENV_PUBLIC_KEYS`）。它在两层里身份不同：

- **比较层**：就是一个普通键——和别的键一起规范化、一起比，没有特权；
- **渲染层**：是覆盖键——非空即整句采用，此时公共键不参与渲染（仍参与比较）。

`text` 为空串等同缺失，渲染回落到骨架 / 兜底（实现落点见 §5 的 `canonical`）。

**作者契约**：用了 `text`，`text` 就是 AI 可见环境的全部；公共键的变化**不会**自动反映到 `text` 里。
只改公共键、不改 `text`，AI 会收到通知但看到的话没变——这不是平台 bug，是 `text` 的契约。
不想背这条就别用 `text`，让平台骨架渲染公共键；要「结构化事实参与比较 + 自定义措辞」时才同时给。

## 4. 公共键（平台提供渲染）

公共键是平台**送的便利，不是约束**：平台渲染它认识的键，忽略不认识的键，所以插件可以自由扩展维度。

| 键 | 骨架 |
|---|---|
| `channel` | 你在 {channel} |
| `origin_name` | 「{origin_name}」 |
| `member_num` | {member_num} 人 |
| `full_mode` | 全量模式 / 仅 @ 唤醒 |

渲染优先级：`text`（非空）→ 公共键骨架 → 通用兜底。

私有键只参与比较，不参与渲染；要让 AI 看到，就写进 `text`。

## 5. 判定（一条路径）

```python
canonical(v) = json.dumps(
    {k: x for k, x in v.items() if not (k == ENV_TEXT_KEY and x == "")},
    sort_keys=True, ensure_ascii=False,
)
```

> 变更 ⟺ `canonical(现值) ≠ canonical(已告知值)`

| 已告知 | 现值 | 判定 |
|---|---|---|
| 有值 | 相等 | 不变 |
| 有值 | 不等 | 变更 |
| 有值 | `None` | 环境消失，变更 |
| `None` | 有值 | 环境出现，变更 |
| `None` | `None` | 不变 |

新会话帧**首次取值 = 建立基线**，不算变更——否则 AI 一进群就先收到一条假的「环境变了」。

## 6. 职责边界

| 事项 | 归属 |
|---|---|
| 判断什么环境、怎么取 | 插件（`environment` 的实现） |
| 何时取值、如何比较、置脏、作用域、投递、解锁 | 平台 |
| 推送（`report`） | 可选；与拉取进同一判定口，不另立判定 |

## 7. 故障语义

`environment` 抛异常或返回非法类型 → 丢弃本次，保持已告知值不变，记 error。
**不得**降级为 `None`——那会产生一次假的「环境消失」通知。连续失败必须可观测（日志计数）。

## 8. 兼容

字段只增不减；平台永远忽略未知键。公共键重命名属破坏性变更，需新旧并存一个版本周期。

## 9. 测试矩阵

- 比较层：键缺失、`text: ""` 与 `{}` 判定相同、键序无关；
- 渲染层：`text` 覆盖、公共键骨架、通用兜底三条路径；
- 迁移：五种情形逐一断言（含 `有值 → None` 与 `None → 有值`）；
- 新帧首次取值不产生变更；
- 非法返回与异常**不产生变更**；
- 推送与拉取同源（同一判定口）。
